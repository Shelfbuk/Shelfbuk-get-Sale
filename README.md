# Shelfbuk - Злови знижку

Це веб-гра "Злови знижку", створена для сайту Shelfbuk, де гравець управляє котиком, який ловить книжки зі знижками.

## Як грати
1. Використовуй клавіші стрілок вліво та вправо (або 'A' та 'D') для руху котика.
2. Лови книжки, щоб отримати знижку.
3. Знижка збільшується кожного разу, коли котик ловить книжку, до максимуму 30%.

## Технології
- HTML
- CSS
- JavaScript

## Як запустити
1. Скачайте або клонування цього репозиторію.
2. Відкрийте файл `index.html` у браузері для гри.
